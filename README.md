One letter, nothing else: **A for coffee**. Coffee is the more vivid pick — a bold morning jolt with real character, where tea reads quiet and calm. A single "A" lands punchier and truer to a blind judge than a soft "B".

## Run

```sh
node main.ts
```

Node 22+, standard library only, no dependencies. Writes exactly one byte, `A`, to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) — no newline, no punctuation.
